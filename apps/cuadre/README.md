# Cuadre

Contabilidad diaria por producto para Android. La contabilidad, los respaldos y la validación de licencias funcionan sin conexión. La búsqueda manual de actualizaciones consulta GitHub.

- Identificador comercial: `com.cuadre.app`.
- Publicaciones: `cuadre-vX.Y.Z`.
- APK comercial: `Cuadre-X.Y.Z.apk`.
- Manifiesto vigente: `apps/cuadre/actualizacion.json`.
- URL que consulta Cuadre: `https://raw.githubusercontent.com/akiradev990515/aplicaciones-descargas/main/apps/cuadre/actualizacion.json`.

Todavía no se ha publicado una versión comercial en este repositorio. El manifiesto vigente se creará con la primera publicación aprobada. Las APK de pruebas tienen un identificador diferente y se distribuyen como artefactos de revisión.

Cada publicación estable incluye APK, novedades, `actualizacion.json` y `SHA256SUMS.txt`. Las versiones de otras aplicaciones no modifican este canal.
